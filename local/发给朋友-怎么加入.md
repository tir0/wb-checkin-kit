# 帮我签个到（一次操作，2 分钟）

我做了个自动签到的小工具：**每天由我的云端任务帮你签到**，你不需要装任何常驻软件、
不需要注册 GitHub、也跟你的电脑开不开机无关。你只需要跑一次下面的操作，把一个文件发回给我。

你的登录凭据会用**你这一份专属的密钥**加密后再交给我（我拿到的是加密文件，不是你的账号密码）。

---

## Windows 操作步骤

### 第 1 步：确认 WorkBuddy 桌面端是登录状态

打开 WorkBuddy 桌面端，确认已登录（没登录就先登录一下）。然后**不用关它**。

### 第 2 步：保存我发给你的文件

把我发给你的 `join.ps1` 保存到桌面，比如 `C:\Users\你的用户名\Desktop\join.ps1`。

> 微信传过来的文件有时会被系统标记为「来自其他计算机」，如果第 3 步提示被禁止运行，
> 先在文件上右键 → 属性 → 勾选底部的「解除锁定」→ 确定；或按第 3 步里括号内的提示处理。

### 第 3 步：打开 PowerShell 跑一条命令

1. 按 `Win + R`，输入 `powershell`，回车（会弹出蓝色/黑色窗口）
2. 先切到桌面：

   ```powershell
   cd $env:USERPROFILE\Desktop
   ```

3. 把下面这行**整段复制粘贴**进去，回车：

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\join.ps1 -Name 你的昵称 -Notify "你的机器人地址"
   ```

   说明：
   - `你的昵称` 换成英文字母/数字的昵称，例如 `alice`（只能用小写字母、数字、`_`、`-`）
   - `-Notify "你的机器人地址"` 是**可选**的：填你自己的钉钉/企业微信机器人地址，
     那么每天的签到结果会直接发给你。**不想配就把 `-Notify "..."` 整段删掉**，也能用。
   - 好消息：脚本会先验证一次你的凭据是否有效，**过期会当场告诉你**，不会让你白等。

### 第 4 步：把生成的文件发给我

命令跑完后，桌面上会出现一个文件：

```
wb-checkin-你的昵称-日期.json
```

把它发给我（微信传文件即可）。发完建议把它删掉：

```powershell
Remove-Item -LiteralPath ".\wb-checkin-你的昵称-日期.json"
```

## macOS 操作步骤

1. 把 `join.sh` 存到桌面
2. 打开**系统自带的「终端」**（Terminal.app，不要用其他工具的终端），执行：

   ```bash
   cd ~/Desktop
   bash join.sh --name 你的昵称 --notify '你的机器人地址'
   ```

   `--notify` 同样可选，不配就删掉那一段。

产出在桌面：`wb-checkin-你的昵称-日期.json`，发回给我即可。

依赖：`jq`、`openssl`、`curl`。若提示 `缺少依赖：jq`，先装一个：

```bash
brew install jq     # 没有 Homebrew 就先装 Homebrew，或告诉我，我给你另一条路
```

## 常见问题

| 情况 | 怎么办 |
|---|---|
| `无法加载文件 ... 未对文件进行数字签名` | 确认命令里带了 `-ExecutionPolicy Bypass`；仍不行就右键文件 → 属性 → 解除锁定 |
| `读不到本机登录态` | 打开 WorkBuddy 桌面端登录一次再重跑。若仍不行，把整段输出发我 |
| 提示 `HTTP 401` | 你的登录态失效了：桌面端退出重新登录，再重跑 |
| 提示 `HTTP 0` 之类 | 网络问题，稍后重跑一次即可 |
| `本机 .NET 不支持 PBKDF2-SHA256` | 系统太旧，装一下 Windows 更新（需 Windows 10 1809 及以上）再重跑 |
| 不确定能不能用 | 先跑 `powershell -NoProfile -ExecutionPolicy Bypass -File .\join.ps1 -SelfTest`（自检，不读凭据、不产文件） |

## 大概多久要重做一次

你的凭据约 **55 天**过期，桌面端重新登录也可能让旧的失效。出现下面任一情况时，重跑第 3 步
把新文件发给我就行：

- 你自己不再收到签到回执；
- 我告诉你「该账号凭据已失效」。

## 抱歉打扰一句：这个文件要当心

那个 `.json` 文件里同时装了「上了锁的箱子」和「钥匙」，**等同于把钥匙和箱子一起寄出**，
所以只发给我本人。如果你希望更稳妥，用 `-Split` 参数跑：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\join.ps1 -Name 你的昵称 -Split
```

这样密文落在文件里、密钥只显示在屏幕上，你把**两者分两个渠道**发我（例如文件走微信、
密钥走邮件）。任何单一渠道泄露都不足以解开你的凭据。
